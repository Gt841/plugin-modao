墨刀 · 思源桌面嵌入插件 0.0.1（本地预览版）
维护者：Gt841。非墨刀官方插件，与墨刀无隶属关系。

安装
将 package.zip 解压到思源工作空间的 data/plugins/plugin-modao/ 下。
确保 plugin.json 与 index.js 直接位于该目录，不要再嵌套一层文件夹。
重新启动思源，在设置 / 集市 / 已下载 / 插件中启用“墨刀”。
首版仅支持思源桌面主窗口（Windows、macOS、Linux），不支持独立文档窗口、浏览器端和手机端。

使用
1. 点击侧栏的墨刀图标，选择“打开墨刀工作台”。
2. 在插件页签中的墨刀官网自行完成登录；无需提供任何 Cookie 或 Token。
3. 登录后点击页签上方或侧栏标题旁的“刷新目录”。
4. 单击个人文件、组织、空间或文件夹名称展开/收起；单击文件名称打开编辑器。
5. 同一文件重复点击会聚焦原页签；关闭后可重新打开。
6. 退出按钮需二次确认：先保存编辑内容，再关闭插件页签并清除此插件会话。

首版范围与验证边界
- 已实现个人文件、组织、空间目录的读取适配；目录加载采用墨刀网页内部接口，不是稳定公开API。
- 已根据墨刀公开客户端确认 proto2、prototype、design2 三类文件的编辑路由；其他类型回到工作台打开。
- 尚未完成真实账号登录后的端到端验收。构建成功和模拟测试通过不等于线上目录/编辑器已验证。
- 已观察接口没有分页参数；若返回后续页标识，会提示列表不完整，不猜测翻页接口。
- 新建、重命名、删除、移动等操作请在墨刀工作台内完成，本插件不直接调用这些写接口。
- 外部授权、新窗口和下载等特殊流程尚未逐一验证；不支持的流程请使用“浏览器打开”。外部浏览器需要单独登录。
- 为安全起见，不允许插件WebView跳转到墨刀域名以外的顶层页面，不开启任意弹窗。
- 源码私有仓库：https://github.com/Gt841/plugin-modao；尚未发布Release或提交集市上架。

隐私
会话仅保存在 Electron 独立分区 persist:modao。
插件不读取、导出、复制浏览器 Cookie、密码或 Token，也不将凭据保存到思源插件配置中。
目录GET在墨刀页面同源执行，由网页会话自动认证；只返回树所需字段及用户身份存在标识。
退出登录只清除此分区，不清外部浏览器、博思白板或PPTGo的登录状态。

开发
Node.js 24，npm install，npm test，npm run check，npm run build。
构建生成 dist/ 和 package.zip；不依赖本机思源固定安装路径。
测试中的目录与账号均为明确的合成fixture，不来自真实账号。
基础构建结构参考本工作区PPTGo插件；保留MIT许可证声明。
